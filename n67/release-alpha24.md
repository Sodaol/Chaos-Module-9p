# Chaos 9 Pro 2.2-alpha.24

适用 N67 中国版 3.1.190。包含一般版和彩蛋版两个独立可选安装档；二者使用同一应用/表盘 ID，不能同时驻留。
更换版本前先重启手环，再发送所选 bin 并在安装器表盘按运行。不要在一次开机内先后注入两个版本。

## 本次修改

- 删除 Chaos 设置中的重复“关于”，仅保留主页“关于”。
- 移除系统背景/模糊和背景恢复入口，也移除实际生成、快照和读取旧背景设置的运行流程。
  旧页号保留为空页，不删除用户导入的素材。
- 一般列表主文字放大到 28px、副文字 22px，标题 28px；一般行至少 88px，双行至少 112px。
  长文字明确启用原生换行并计算更高的行盒。系统关于自定义字段也启用换行并重新对齐后续字段。
- Chaos 关于页增加“移植：meowl”。系统设置中的 Chaos 入口不再显示箭头。
- 应用列表缩放、排距、内缩缺省全部关闭；用户曾明确保存的开关选择继续保留。
- 键盘改为完整数字/QWERTY 一屏排版，取消横向滚动，缩短标题并清除窄键的主题内边距。
  保留 42 键、大小写、空格、删除、清除、点号和保存。
- 设置入口与桌面容器使用生命周期检查及快取；减少重复遍历。
  桌面效果全关时不再扫描网格，稳定排版表降为周期检查。
  Chaos 列表滚动事件只登记时间；滚动期间暂缓字体/资源/排版扫描，停止约 180ms 后恢复。
  原生资源重复扫描降频，单纯更新勾选时不再重复排版文字。

## 两个版本

一般版：保留应用列表和系统设置中的 Chaos 按钮；系统设置按钮没有箭头。

设置彩蛋版：不创建桌面图示，也不在系统设置列表追加 Chaos 按钮。
安装后进入“系统设置 → 关于本机”，连续点击系统版本显示文字 5 次打开 Chaos。
每两次点击间隔须小于约 1.2 秒；离开关于页、熄屏或目标控件销毁后重新计数。
彩蛋版内部隐藏“应用列表显示”和“系统设置入口”选项，避免意外变成普通入口。
此入口仍需本次开机先注入 Chaos，用户已要求暂不做真正自启动。

## 验证与限制

桌面 ARM 验证包含两种版本的页面、原生控件、RTC、应用保护与排序、注入流程、完整键盘和文字换行。
彩蛋专用检查验证 5 次点击、超时/离页/销毁重置，并直接执行该版注册器，确认没有调用桌面新增流程。
滑动检查限制树读取次数，验证滚动回调不分配对象，后台排版在滚动时暂停并在停止后恢复。
这些检查不代表手环上的 CPU 百分比或帧率测量；实际快速滑动效果仍需真机确认。
系统原生滚动绘制本身仍会消耗 CPU。此前系统拒绝震动请求的问题没有在这版修复。

缓存清理、自启动和系统更新页入口维持移除/暂不适配。
应用 ID 0xE7D4，首页 0xE7D40000，安装器表盘 ID 990000000029。
