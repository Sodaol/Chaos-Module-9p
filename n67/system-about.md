# alpha.21 系统关于页面修改

入口：Chaos → 设置 → 系统关于页面修改。
四类独立设置：版本显示、系统文本、设备名称、型号。各页可选系统默认、预设或自定义，
自定义使用英文数字键盘（31 字符，大小写、空白、小数点、删除和清空）。版本栏不接受空白。
每栏选择系统默认会恢复该系统关于页的原始显示；只修改原生关于页的标签。
不写 /system/version/version.ini，不改变蓝牙名称、MAC、序列号或实际设备身份。

配置 /data/chaos/n67-system-about.bin：144 字节、NSC1、FNV 校验、临时文件加 rename 提交。
写入失败保留旧配置与输入页，使用系统短提示报告结果。
只在原生关于页 key=0x0016001b、亮屏且四个目标均为该页标签时应用。
页面 key 来自 AP 的原始描述符 0x2c7dfb3c，on_create=0x0c2d6514；
标签类从 lv_label_create 的字面量 0x0c25ebd4 核对为 0x2c6834b0。
目标槽来自关于页对象表 0x200cd088：名称 +0x10、型号 +0x18、系统文本 +0x28、版本 +0x34。
按原生对齐链重排后续标签，不改 MAC / SN 字符串。根对象 DELETE 事件清理快照，避免地址复用后
误用旧原值；同一页面和配置不重复写标签。

新增 6 页（菜单、4 个字段、键盘），共 28 页，仍在原先 8192 字节描述符块内。
键盘按键使用 N67 原生按钮，保留水平滚动视口与固定操作区。

## 同版界面调整

时间/日期使用 64px 字体、132px 宽的双滚轮，原生 PAD_ROW=0，使原生计算出的滚动窗口一同放大。
共同中心 y=168；按固件可见三行公式 (2×0.8+1)×font_height - 2×pad_row，
64px 字体对应约 166px 的可见高度，尺寸以实际原生字体度量为准。
一般列表字号不跟随增大。

操作结果只使用系统 toast，移除应用管理、模糊、诊断、震动、日志和时间/日期页的结果占位列。
CPU、存储、内存等资讯卡恢复原生背景，仍不可点击；空资料的防御性隐藏保留。
缓存清理完成仅 toast 报告结果，首行重新显示扫描资讯。

## 验证

15 项桌面检查。新测试在三个装载地址执行实际 ARM 的六页路由、四字段独立保存/恢复、
原生页 key / 标签类、布局链、MAC / SN 不变、42 键输入与失败回滚、重启读配置、坏配置拒绝。
原生系统关于页渲染与滚轮实际触控仍待设备确认。
