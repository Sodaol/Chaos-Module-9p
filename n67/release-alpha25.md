# Chaos 9 Pro 2.2-alpha.25

适用 N67 中国版 3.1.190；一般版、设置彩蛋版两个可选安装档。沿用 alpha.24 的其他设置与界面。

修复系统关于页面的系统版本、系统文本、设备名称和手环型号的长文字显示。
上一版只启用原生自动换行，且长字符串测试仅覆盖设备名称，本次四字段全部补测。
现在在显示副本中按行宽插入明确换行，先设置标签宽度与换行模式，再填入文字并调整高度、对齐下方字段。
原本保存的字符串不加入换行，重新打开键盘仍是完整原文字。
低频核对自定义显示；若原生页面刷新覆盖其文字或换行模式，会恢复分行与高度。系统默认字段不做周期覆盖。
MAC/序列号不修改。彩蛋版依然连点系统关于的版本文字5次打开。

新增测试使用四字段各31字无空格字符串，验证分行、保存文字不变、原生刷新后的恢复和 MAC/SN 保留。
一般版20项、彩蛋版17项桌面验证；OS/LVGL有模拟，实际显示仍需手环确认。

两版使用相同应用与表盘ID，必须择一安装；请先重启手环，再发送所选bin并按运行。
