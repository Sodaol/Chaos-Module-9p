# Chaos 9 Pro 2.2-alpha.23

适用 N67 中国版 3.1.190。沿用应用 ID 0xE7D4、表盘 ID 990000000029 和已确认能注入的 v2.1 引导链。
本次按 10 Pro Chaos 1.0.8 的功能核对补齐，不修改固件或系统启动脚本。

## 新增实际适配

- 系统美化 → 应用列表设置：RW6 缩放、排距、外列内缩三个原生开关，选择持久化。
  定位 N67 原生网格类和仿射表，按 96px 图示与 336×480 屏幕调整；支持一般/编辑模式。
  关闭单项会恢复该项捕获的系统原值；列表布局和其他应用对象不写入，未变化时不重绘。
- 重新载入恢复字体和图标：记录最后选择，重启后重新注入 Chaos 时自动恢复。
  配置双副本、代数和校验；素材遗失时保留系统默认，不尝试加载不存在的字体。
- 重新载入恢复背景：独立记录是否恢复背景，保留现有背景来源、自动跟随和区域选择。
- 应用列表显示：可以隐藏/显示 Chaos 自己的桌面入口，仍能通过系统设置入口进入。
  复用现有保留排序的显隐流程；不解除系统应用的保护，不删除排序记录。
- 安装器设置：增加“注入系统设置”“应用列表显示”，运行前保存；运行中禁止改入口配置。
- 安装器增加重启与两次确认的重置设置。重启延后到定时器执行。
  重置仅清除列出的 Chaos 偏好，保留导入字体、图标、background.bin 与应用显隐策略；完成后需重启。

本版共有 29 个注册页号（缓存清理旧页号保留为空页）。操作结果仍使用系统短暂提示。
CPU/内存/存储卡背景、9P 原生设置按钮尺寸，以及前版同步的主页/关于/安装器排版保持。

## 功能核对

| 10P 功能 | N67 对应状态 |
|---|---|
| CPU、存储、内存 | 已有信息页，按 9P 的 proc 接口读取 |
| 应用隐藏、显示全部、排除项 | 已适配 9P 注册表和实际排序链；系统应用保护保留 |
| 文件/终端、文件查看编辑 | 保留 N67 文件引擎、交互 NSH 与脚本入口 |
| 字体选择、恢复、删除 | 保留 8 槽管理；新增选择记忆与重新载入恢复 |
| 桌面/系统资源图标包 | 保留 N67 资源映射、缺件回退与删除；新增选择记忆 |
| 桌面 RW6 三项排版 | 本次新增 N67 原生表适配，非直接写图像位置 |
| 背景、模糊、快照、固定图片 | 保留 N67 BGRA/快照流程、自动跟随与四区域；新增恢复开关 |
| 表盘列表、切换、摇一摇轮换 | 保留 N67 表盘管理器及手势订阅 |
| 时间与日期 | 原生双滚轮、RTC 写入、回读与错误短提示 |
| 亮度 | N67 自动亮度/临时手动亮度，按本机 600nit 上限 |
| 系统关于修改 | 版本/系统文本/设备名/型号，预设、自定义键盘与恢复 |
| 设置入口、可选桌面入口 | 已接入，桌面入口开关为本次新增 |
| 日志、关于、许可、五击诊断导出 | 保留 |
| 安装器运行、入口选项、重启、重置 | 本次补齐 N67 支持的控制项 |
| fetch 恢复模块 | 9P 已有 fetch，沿用系统；不装 10P 模块 |
| 震动测试、滑动震动 | 保留请求与诊断；此前系统拒绝导致不震动的问题未修复 |
| 自启动 | 按用户要求暂不适配；随安装器载入不等于系统自启动 |
| 缓存清理 | 按用户要求移除 |
| 系统更新页入口 | 9P 无对应页面，移除 |

桌面检查验证代码路径、原固件仿射构造/取值函数和应用排序等，OS/LVGL 渲染仍有模拟。
不能把这些检查当成手环实测，尤其桌面动画观感、触控和马达效果仍需真机确认。

## 安装

先重启手环，再发送本版 bin，切到 Chaos 安装器表盘后点“运行”。
“重新载入恢复”会在 Chaos 被重新注入后生效，不会在 Chaos 尚未加载时执行。
建议首次测试新桌面功能时，依次切换三个开关并确认全关能恢复原布局。
