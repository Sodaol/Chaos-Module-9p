# alpha.31 一般版

修正設定入口圖示和文字誤用 BOTTOM_LEFT，改為 LEFT_MID；維持圓形64px圖示、無箭頭與原生列尺寸。

參考10P背景模式，重新適配9P的錶盤擷取、靜態通透／軟體模糊、變暗與區域開關。不是逐幀模糊。系統美化新增「背景模糊」；模式預設關閉，點模式依序切換「通透背景」「模糊背景」「關閉」。選模糊背景後，按「從錶盤生成背景」，返回錶盤等待生成，再打開應用列表／控制中心查看。支援辨識到的啟動器、控制中心、小部件、通知中心根容器；不更改錶盤本身，並不表示所有系統子頁已完成適配。

生成分批處理，亮屏才工作，滑動時暫停；模糊後重用圖片，穩定頁面降低掃描頻率。最多保留一份原圖及兩份輸出緩衝，約1.85MiB；實際生成瞬間的停頓、CPU和記憶體仍需實機確認。關閉會還原已管理的原生背景樣式。新開關不沿用早期已移除版本的舊背景配置。
