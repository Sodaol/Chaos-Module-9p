# alpha.36 一般版

修正搖一搖的N67手勢主題metadata位址，從錯誤的0x2c67d0a4改為原生系統訂閱使用的0x2c67c708。事件格式依原生handler核對：metadata在+4、payload指標在+0x18、長度在+0x1c、手勢碼在payload+8。拒絕錯誤主題、短資料、無效指標及抬腕事件。

修正介面初始開關顯示開啟、實際初始關閉的不一致。開啟時若訂閱失敗會提示，重開可重試，不重建常駐計時器。切換仍由GUI執行緒消費，不在事件派發執行緒直接切換。以原生watchface manager +0x6c/+0x6d檢查AOD與可見狀態；消費事件時再檢查亮屏及前台，冷卻期間不排延遲額外切換。

離開輪換列表後重新讀取引擎當前錶盤，避免沿用舊列表狀態；只剩目前錶盤符合參與條件時不重新載入同一張。

用法：安裝前重啟手環，載入後在「錶盤管理」開啟「搖一搖」，於「搖一搖輪換」選至少兩張參與；如要輪換內建錶盤，開啟該頁的內建錶盤選項。回到一般錶盤、亮屏時搖動測試。開關暫不跨重啟保存。

保留設定入口位置與重寫的背景模糊。僅一般版。ARM／桌面驗證不代表實機感測器事件已確認。
