# Chaos 9 Pro 2.2-alpha.26

适用 N67 中国版 3.1.190。一般版和彩蛋版共用 ID，择一安装，升级前先重启。

## 修复应用列表显示开关

原来的应用模块能移除 Chaos 图示，但安装器常驻注册器每600ms会把图示缺失当成异常并重新添加，导致“关”不生效。
现加入同一常驻内存中的显示偏好：注册器遵守用户关闭选择，不再强制清除自己的 hidden 位并加回图示。
再次进入安装器产生另一个注册器时，也会通过已注册主页描述符寻找当前应用的偏好，避免第二个修复流程覆盖选择。
一般版 Lua 安装成功判断改为原生注册器成功态与应用节点，不再要求关闭显示时仍存在桌面图示。
安装器注入后仍允许修改应用列表显示偏好，运行中的应用在亮屏空闲时约1秒内读取新选择；滑动中暂缓读取。
应用内开关在 UI 定时器下一拍执行，移除原来的3秒初始等待。保存失败保留原设置；其他应用、排序和系统应用保护保持。

## 系统设置入口图示

使用 Chaos 原图生成64×64 BGRA图示，安装时写入 /data/chaos/chaos_settings_icon.bin。
通过 N67 原生列表的 leading icon 参数显示，沿用相邻系统按钮尺寸，无右侧箭头。
彩蛋版仍按 alpha.24 定义仅由系统关于版本连点5次开启。

保留 alpha.25 的四字段明确换行，及之前的列表滚动维护降频、单屏键盘、移植署名等。
新增把原生常驻注册器与应用显隐定时器交错执行的测试，覆盖隐藏、重复安装器、重新显示无重复图示和保存失败。
设置入口测试验证图示路径和无箭头；图片显示仍需手环确认。
一般版20项、彩蛋版17项桌面检查；不是实机验证。
