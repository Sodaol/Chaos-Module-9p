# N67 原生控制项（2.2-alpha.15）

适用固件：N67 CN 3.1.190。保留应用 ID 0xE7D4、安装器表盘 ID 990000000029。

## 应用内替换

| 控制项 | 系统入口 / 类 |
| --- | --- |
| 列表列 | create 0x0c2702b4；fill 0x0c275ad4；update 0x0c276ae4 |
| 列表开关、勾选框、箭头 | 系统列内置 trailing 1 / 2 / 3，控制句柄在 +0x60 |
| 标题、返回和时钟 | 0x0c275500，系统管理时钟刷新 |
| 时间、日期滚轮 | 0x0c4349d4 / 0x0c434a54 / 0x0c4349f0 / 0x0c43ba44 |
| 按钮 | 0x0c43da64；时间/日期确认与文件管理器按键对象池 |
| 删除确认弹窗 | 0x0c271d6c / 0x0c274f60，绑定当前页描述符 |
| 进度条 | 原生 LVGL bar 类 0x2c683310，值设置 0x0c25bc38 |
| 文字、图片、容器 | 原有 N67 LVGL 实现；品牌内容与各页布局仍由 Chaos 组合 |

原生列表列 +0x50 是主标签，+0x54 是副标签；+0x71 控制点击转发。
原生开关发送 VALUE_CHANGED=29，适配层映射到上游业务的 30。
开关只处理值变化，忽略额外的 CLICKED；勾选行关闭系统转发，避免一击执行两次。
列表沿用系统类 112 px 行高。特殊品牌展示、日志/授权正文和文件键盘仍有专用布局，
其底层使用原生标签、图片和按钮，不表示这些整页是系统现成页面。

## 安装器边界

安装器仍使用系统 Lua LVGL 暴露的 Object/Label/Image。
固件导出构造表 0x2c75e084..0x2c75e0dc 只含 Object、Calendar、Checkbox、Dropdown、
Image、Keyboard、Label、Led、List、Roller、Textarea；没有系统专用列表列、标题、
按钮、消息框的 Lua 构造绑定。未在安装前提前加载原生模块来绘制安装器，保留先前载入卡顿修复。

## 固件证据

列表类 0x2c68da78；构造入口 0x0c2702b4；系统填充调用例 0x0c2c78fa..0x0c2c791a。
trailing 工厂 0x0c27048c，开关类 0x2c68daf8、勾选类 0x2c68dad8。
开关点击处理 0x0c43375c..0x0c4337d0，列表转发处理 0x0c26f6e4..0x0c26f71c。
系统消息框使用例 0x0c2c7d9c..0x0c2c7dda，绑定页描述符后调用 fill kind=5。
新增入口均纳入安装器固件指纹；实际样式与触控仍待实机确认。

## 验证

13 项桌面检查，3 个 ARM 装载地址。新增 test_native_ui.py 实际执行固件的列表转发与
开关点击处理，覆盖事件码、重复点击排除、勾选转发关闭。其余原生绘制、分配和事件传输
使用显式替身；这不等同于在设备上验证原生控件渲染。
