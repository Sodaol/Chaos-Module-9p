# alpha.20 空白列与系统短提示

## 空白来源

应用管理、系统模糊、调试和震动测试等页总是建立状态列，初始 MESSAGE / STATUS 为 NUL 空串。
原生列表仍绘制完整卡片与占位高度，看起来像没有文字的按钮。
本版从共用 build_row 的 display 分支处理：空文字且空副标签时隐藏对象、高度归零，
保留句柄供既有调用方使用；对齐链跳过该占位。非空资讯列设透明并取消点击标志，
操作按钮、开关、确认弹窗与关于页品牌区域不受影响。

## 系统短提示

使用 N67 固件自带 toast 入口 0x0c36f064(text, milliseconds)，不写入通知中心。
系统原始调用证据：0x0c2fe5a0..0x0c2fe5aa（静音模式提示），
0x0c298938..0x0c298942（米家场景执行中提示）。
原生包装器设置 r0=0x0c373c19 绘制回调、r1=duration、r2=0、r3=text，调用 0x0c36ef10。
原生核心保存 text 到对象 +0x44，同步调用回调创建标签；持续时间交给系统管理。
新增相关固件入口指纹校验。

保存时间/日期、应用显隐与批量完成、更新排除项、清空日志、清理缓存、背景生成完成
会请求短提示。诊断和长篇错误仍保留可读取文字，删除确认保留系统对话框。

request 把 NUL 之前的文字复制到 192-byte 队列，按 UTF-8 边界截断。
共用 UI 定时器在页面重建后搬入独立常驻缓冲，再显示 2500ms 的系统 toast。
同拍以最后一条为准，不因页面打开/滚动/重绘重复弹出；息屏或非 Chaos 前台会丢弃待发提示。
没有新增原生定时器、马达调用或外部服务。

## 验证范围

14 项桌面验证，3 个 ARM 装载地址。新增 test_notifications.py 检查空状态隐藏、
资讯不可点击、真实固件包装器 ABI、延后显示、文字生命周期、无重复提示、息屏/前台门限。
系统绘制核心仍是明确的测试替身，尚待设备验证最终 toast 外观与位置。
