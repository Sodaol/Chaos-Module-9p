# N67 装载链与 ABI 记录

原版 P67 使用 insmod 与 LVGL 9。本版保持上游页面和状态机，新增条件编译 `n67`，切换固件 API 和字体实现，使用 N67 已验证的内存注入注册链。P67 编译默认不启用 n67。

1. Lua 先核对系统版本，再调用注入桥接器。桥接器校验 66 个固件入口各 8 字节和应用/页面注册表形态。
2. Rust 以 `0x1D100000` 链接，输出 text/rodata/data 和补零 BSS。LLD 解析内部 Thumb 分支；打包器拒绝未解析的运行时引用和未知重定位；仅允许已丢弃 ARM unwind 节中残留且无分配节引用的两个 personality 符号名称，只保留内部 ABS32 位置。
3. 安装器解压模块，malloc 分配独立常驻内存。执行别名 `exec = heap - 0x20000000`。对每个 ABS32 写入 `old + exec - link_base`，一次 memcpy 到新内存，同步指令缓存。
4. 分配 8192 字节描述符块。`chaos_n67_init(base, gesture_bubble, event_bubble, press_lock)` 填写 15 个页节点与页指针数组。标志位从当前 Lua LVGL 导出，避免套用标准 LVGL 枚举。
5. C 桥接器在固件 GUI 定时器中调用 `app_register(app, pages, 15)`，验证 app_find/page_find，再加入启动器。
6. 页面回调和周期任务全部指向常驻 Rust 模块。安装表盘释放后，模块和描述符不释放，因此不依赖表盘 Lua 的定时器。重启后固件恢复原注册表。可选自动重装由系统正常加载当前安装器表盘触发，不是任意表盘背后的系统自启动。

应用 ID `0xE7D4`，页键 `0xE7D40000 | pid`。第一页指针数组在描述符块 `+0x800`。第 0 页在 `+0x40`，其余从 `+0x1000` 开始，步长 112。N67 默认入口 helper `0x0C43FA46` 查 app `+0x2C` 的页数组，再返回数组 `+8` 的第一项；已经执行实际固件这段代码验证首页选择。

112 字节页面：名称 `+0x10`、页键 `+0x14`、root `+0x2C`、signal `+0x30`、create `+0x48`、resume `+0x4C`、pause `+0x54`、destroy `+0x60`。root 由固件管理；模块只清除自己保留的句柄，不重复删除 root。确认框关闭延迟至 GUI 定时器，避免在当前控件事件派发中删除发送者。

N67 LVGL 8 字体包装体为 28 字节，包装体的所属记录指针在 `+28`。管理器指针 `*(0x200BFC54)`：字体记录链 `+0`、包装体链 `+12`、名字/文件路径链 `+24`，三条链的链接偏移分别为 48、32、8。热替换只修改已识别的 MiSans 字体体和关联包装体，保留所有权指针；每次写前重新枚举并检查前后链及尾节点。恢复时再次核对记录、字体、字号和上一次写入内容，避免陈旧地址写入。

图标更换修改 app 注册节点 `+0xC` 的路径；新路径使用固件堆复制，原路径保留用于还原。素材采用 N67 的 LVGL 8 4 字节头和 BGRA8888 数据，不使用 P67 的 LVGL 9 头。切换清理旧图像缓存、刷新启动器；系统资源改用 N67 LVGL8 图像对象：class 0x2C68260C、source +36、尺寸 +44/+46；遍历当前 screen/top/sys 层，监听 DRAW_MAIN_BEGIN=21 和 DELETE=35。设置源使用固件 0x0C2607D9，保存原路径并恢复，不套用 P67 文件系统驱动钩子。准确路径和尺寸来自 N67 AP 字符串与 system/image 资源目录，列于 system-icon-mapping.json。

固件地址映射 `runtime = file_offset + 0x0C080000`。各入口的地址与校验字节在 `n67/generated/firmware-fingerprints.json`。外部固定接口与 RAM 地址只在 N67 适配代码中使用；本版不提供跨固件自动扫描，不支持其他版本硬装。

## C 文件引擎与数据分块

15 个页节点中的第 14 页使用独立 C 文件/终端引擎；14 个原 Rust 页保留。C 的页面回调、消息表及 worker 地址均链接到同一个常驻模块，参与 ABS32 重定位。`n67/files/core.c` 和 `platform_n67.c.in` 来自此前文件管理器 v6，`integration.c` 将 54 个 N67 API/枚举及原生回调填入堆状态，不保留安装器 Lua 指针。

C 编译禁止 MOVT 地址拆分和跳转表（Clang target feature +no-movt）；链接器解析内部 Thumb 分支，装载时修正 ABS32。编译器随机失败最多重试 60 次，不跳过 ELF 校验。原生 image 含 BSS，压缩为 60000 字节上限的 chaos-NN.dat 文件叶，由打包 Lua核对长度/字节和后解压；这规避了 N67 单文件 16 位长度限制，不使用 Lua load 执行数据文件。

自动安装开关存于 /data/chaos/auto-install。安装器加载后等待 3 秒，沿同一版本与入口指纹校验链安装；失败间隔重试，最多 3 次。它不修改 /system、ROMFS rcS、AP/BL2、持久启动项，不能提供换表盘后重启自动驻留。
