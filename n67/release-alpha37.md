# alpha.37 一般版：搖一搖現場診斷

使用者確認一般切換正常、搖一搖仍無反應。本版增加原生事件現場讀值，尚未宣稱修復實機觸發問題，亦未放寬錶盤可見／前台安全判定。

錶盤管理新增「搖一搖狀態」與「清除手勢記錄」。統計訂閱有無、原始回調數、辨識搖動數、最近手勢碼、未切換原因、該事件前台ID及AOD/VIS、排隊數、切換完成數與可見狀態阻擋次數。回調只使用原子計數，不配置物件、不繪圖、不直接切換。狀態列在錶盤管理顯示時每秒更新，離開後不重畫。

測試：重啟後安裝並開啟搖一搖，確認至少兩張參與輪換；按清除手勢記錄，返回平常錶盤並保持亮屏搖動數次，再進錶盤管理滑到狀態列，回報完整畫面。事件為0指向事件來源或訂閱鏈；事件增加但搖動為0表示沒有收到0x1c2（十進位450）；搖動增加但排隊為0則看狀態及阻擋次數；已排隊但未切換則看候選條件或介面結果。
