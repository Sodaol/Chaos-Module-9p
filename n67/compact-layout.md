# alpha.17 字号与坐标修正

用户确认 alpha.16 可注入，反馈字过大、页面偏位。本版仅调整应用 UI，保留 v2.1 注入相容层、新 ID。

原生列表的标签不是直接挂在外层列上：row+0x4c 是文字容器，+0x50/+0x54 是其内标签。
先前将外层列的偏移再次写到内层标签上，会造成重复缩进；原生主题默认字号也未限定。
本版在 native fill 前设置 PRIMARY / SECONDARY 字体，再在 fill / update 后统一内层几何。

- 主字 22px，副字 18px；单行 80px，双行 96px，左右 16px。
- 标题 22px、时钟 18px，分配独立宽度，避免互相占位。
- 标签相对内层容器左上角为 (0,0)，开关与勾选框靠右居中。
- 首页进度行独立 104px，修正文字容器与进度条重复偏移。
- 关于页动作文字使用内层坐标，品牌与既有居中保持。
- 滚轮字体固定 32px，两轮使用同一 CENTER 锚点；编辑页清零列表的 32px 底部留白，
  防止中心锚点被留白推高。中间分隔符与两轮共享中心线。
- 系统原生控件继续保留，不恢复自行拼装的开关。

桌面 ARM 检查回读实际样式字号、标签父子层级、标题与时钟边界、滚轮锚点，
并保留原生事件、防重复切换、RTC 与注入回归检查。仍需实机检查最终渲染。

## alpha.18 标题跑马灯

固件 0x0c2701be 为标题标签设置 LONG_SCROLL_CIRC=3；本版在原生标题创建后，
通过 0x0c2644d8 将标题与时钟设置 LONG_DOT=1，并清除标题容器 SCROLLABLE。
保留字号与固定边界；过长标题省略显示，取消横向或纵向滚动动画。

## alpha.19 时间/日期页放大

按用户反馈，仅将编辑页数字由 32px 放大到 48px，滚轮各由 86px 加宽到 112px，
两轮中心为 x=96/240，仍显示三行；确认键由 160×80 放大为 224×88。
单位标签 22px，分隔符 32px，状态置于 y=264。保留共同中心 y=168，
按钮底部为内容 y=392 / 屏幕 y=448，不压到最后 32px 手势区。
一般列表与标题的 22/18px 字级保留；包含 alpha.18 标题跑马灯关闭修正。
