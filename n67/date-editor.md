# alpha.12 日期编辑

日期页使用独立排版：顶部 YYYY / MM / DD，年/月/日三列，蓝色标记选中列，
下方减/加并排、保存日期按钮与状态提示。所有操作位于 424px 内容范围内，
不改变其他列表的公共行高。原有操作槽号不变，事件仅排队，由 UI timer 执行。

RTC 写入保留现有 N67 UTC 转换：读取当前时区，修改日期时重新读取当下时分秒，
写 `/dev/rtc0` ioctl 0x1902；写后回读系统时间核对。失败显示 rc，不能将请求
成功当作设备端已验证。手机后续校时仍可能重新同步日期。

重新核对 N67 3.1.190：rtc_ioctl=0xc0c80bc，SET_TIME=0xc0c813c；成功后
0xc0c8152 调 clock_synchronize=0xc4db9ac。追加固件入口指纹。
之前 time_set.rs 的注释包含 P67 旧地址，本次以以上 N67 位址为准。

test_datetime.py 执行实际 ARM 日期编辑、日期布局与 UTC 转换，覆盖閏日、月底、
跨日、正负时区、编辑后时间继续流逝与失败状态。另执行固件 rtc_ioctl 分支，
检查成功才同步时钟。底层 RTC、互斥锁、BASEPRI 与时钟同步为明确测试替身，
不等同于实机硬件测试。
