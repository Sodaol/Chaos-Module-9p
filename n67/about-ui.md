# 2.2-alpha.7 关于 Chaos 页面

## 2.2-alpha.8 对齐修正

alpha.7 错把布尔值 true（1）当成文字置中。LVGL 8 的 `lv_text_align_t`
实际为 AUTO=0、LEFT=1、CENTER=2、RIGHT=3，因此实机名称与版本等文字靠左。
现在明确设置 CENTER=2，并以 ARM 执行后实际写入的文本样式检查名称、版本、
设备/固件及署名四个标签，避免只看绘制示意图而遗漏实机参数。
依据：https://github.com/lvgl/lvgl/blob/v8.3.11/src/misc/lv_txt.h

本次界面调整仅作用于「关于 Chaos」，沿用原应用图标。

- 上方透明品牌区集中显示图标、Chaos、版本徽标、设备/固件及上游项目署名。
- 三个功能入口改为 52px 高的圆角列表，提供右侧指示与更清楚的文字层级。
- 版本区仍使用 slot 0，保留原有连续点击五次进入诊断的行为。
- 运行日志、AGPL-3.0 与 MPL-2.0 入口保留原路由及 slot 2/3/4。
- 专属排版在 `fw_api::about_identity/about_action` 内，不改变公共列表的默认样式。
- 复用 `/data/chaos/chaos_icon.bin`，不新增动画、周期刷新或额外安装资源。

检查完整页面生命周期、日志与两项授权导航、诊断开关及导出。排版 PNG 是依
同样的坐标、字体与原图标绘制的示意，时间为示例，不是设备截图或遥测。
GUI、字体和存储的 ARM 桌面测试使用替身，实际显示仍需手环确认。
