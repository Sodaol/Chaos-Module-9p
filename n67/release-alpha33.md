# alpha.33 一般版

背景生成不再要求預先存在背景檔。一般入口改為「從錶盤生成背景」「使用已保存背景」；缺少保存檔時自動改為等待錶盤擷取，並保存來源修正。手動匯入 background.bin 為獨立可選入口，不是使用模糊背景的必要步驟。新增常駐背景狀態列，原生桌面格狀類別可在圖示為記憶體描述符時識別。

用法：系統美化→背景模糊，選通透或模糊模式→從錶盤生成背景→切回平常使用的錶盤等待生成，再打開應用列表／控制中心。若仍顯示等待，回報背景狀態列文字。

系統設定的Chaos入口依相鄰原生列量測圖示尺寸、文字區域、位置及字型；圓形圖示透過原生縮放介面配合尺寸，避免只裁切。保持無箭頭。關於頁的meowl使用與其他貢獻者相同的姓名／角色格式，角色為「移植」。

保留alpha.32分塊注入與延後背景恢復。僅一般版，安裝前重啟手環。桌面模擬驗證不能代替實機顯示確認。
