# 9 Pro 蜂窝视图

适用于国行 N67 3.1.190。打开 Chaos → 系统美化 → 应用列表设置 → 蜂窝视图，再打开系统应用列表。

- 上下左右拖动移动蜂窝。松手后保留惯性。拖动屏幕最右侧 28 像素的区域可缩放，点按图标调用原生应用启动接口。
- 蜂窝与 RW6 缩放、排距、外列内缩互斥。蜂窝开关仅在本次注入期间生效。
- 长按蜂窝图标会临时回到原生列表。再长按该应用即可使用系统编辑或卸载。退出列表后重新进入可恢复蜂窝。
- 首批蜂窝图标在原生刷新回调前准备，其余图标在空闲时补齐。原生桌面对象已经存在时，表盘期间可预建蜂窝，返回时复用。
- 普通拖动不会在内容边缘切换成返回手势。最左缘向右滑可交给系统，右侧保留缩放。拖动和惯性使用 16 ms 定时器，空闲暂停。

排列和手势代码来自 [Chaos v1.1.7 蜂窝实现](https://github.com/WenHuaYiYang/Chaos-Module/commit/687abe6)，采用 AGPL-3.0。9 Pro 适配使用 N67 的桌面顺序、图标来源和启动接口。桌面背景识别也包含蜂窝容器。

`tools/test_honeycomb_n67.py` 在三个重定位地址执行 ARM 代码，核对设置入口、分批创建、双向拖动、缩放、点按启动、拖动不误开和恢复。测试使用 LVGL 替身，实体手环上的帧率、背景渲染和系统转场快照仍待确认。ARM 测试覆盖原生刷新前的首帧，但未执行系统进场快照的生成过程。
