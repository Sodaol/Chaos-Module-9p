# 9 Pro 蜂窝视图

适用于国行 N67 3.1.190。打开 Chaos → 系统美化 → 应用列表设置 → 蜂窝视图，再打开系统应用列表。

- 从屏幕任一侧都可以沿任意方向拖动蜂窝。松手后保留惯性，点按图标调用原生应用启动接口。
- 蜂窝与 RW6 缩放、排距、外列内缩互斥。蜂窝开关仅在本次注入期间生效。
- 长按蜂窝图标会临时回到原生列表。再长按该应用即可使用系统编辑或卸载。退出列表后重新进入可恢复蜂窝。
- 首批蜂窝图标在原生应用列表的建立／恢复回调返回前准备，刷新回调也会补齐。其余图标在空闲时加载。
- 固定触控层接收拖动，并切断向父层传递的滚动和手势链。系统页面管理器发出的滑动返回请求也在蜂窝启用时核对手势。滑到内容最上方并松手，再向下拉约 72 像素后松手返回表盘。两侧边缘均可平移。平移时暂缓图标缩放，停稳后补齐。拖动和惯性使用 16 ms 定时器，空闲暂停。

排列和手势代码来自 [Chaos v1.1.7 蜂窝实现](https://github.com/WenHuaYiYang/Chaos-Module/commit/687abe6)，采用 AGPL-3.0。9 Pro 适配使用 N67 的桌面顺序、图标来源和启动接口。桌面背景识别也包含蜂窝容器。

`tools/test_honeycomb_n67.py` 在三个重定位地址执行 ARM 代码，核对设置入口、分批创建、双向拖动、右缘快速斜拖、点按启动、拖动不误开和恢复。测试使用 LVGL 替身，实体手环上的帧率、背景渲染和系统转场快照仍待确认。ARM 测试覆盖原生建立回调交接、旧表盘可见状态仍为真时的准备工作，以及刷新前隐藏三列。系统进场快照和实体触摸分发仍需实机确认。
